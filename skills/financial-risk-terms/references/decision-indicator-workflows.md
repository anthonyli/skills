# 决策引擎与指标平台联动工作流

## 1. 总体链路

```text
业务系统产生事件
  ↓
接口服务接入原始字段
  ↓
字段映射为系统字段
  ↓
指标平台计算 / 查询指标
  ├─ 实时指标：基于实时事件和历史分片更新
  └─ 离线指标：基于数仓批数据调度结果
  ↓
决策引擎执行策略
  ├─ 简易模式：规则集组合
  └─ 流模式：规则集、模型、函数、评分卡、三方服务、子策略、判断、并行、动作等编排
  ↓
规则 / 模型 / 评分卡 / 函数 / 决策工具引用指标
  ↓
输出风险决策结果
  ↓
记录调用日志、规则命中、指标查询、模型调用、名单命中
  ↓
大盘、策略实验室、回测、分流旁路分析持续优化
```

## 2. 实时指标开发到规则引用

```text
指标需求分析
  ↓
业务数据分析
  ↓
系统字段配置
  ↓
实时数据服务对接
  ↓
实时指标配置
  ├─ 基本信息
  ├─ 指标模板
  ├─ 主属性 / 从属性
  ├─ 计算逻辑
  ├─ 过滤条件
  ├─ 包含当前笔 / 不包含当前笔
  └─ 取值非本字段（需要时）
  ↓
实时指标测试
  ↓
指标上线
  ↓
指标审核
  ↓
实时指标初始化（需要历史窗口时）
  ↓
指标授权
  ↓
决策引擎规则 / 模型 / 评分卡 / 函数 / 决策工具引用
```

关键判断：如果规则页面看不到实时指标，优先检查上线、审核、授权、机构、渠道和指标类型。

## 3. 离线指标开发到规则引用

```text
指标需求分析
  ↓
业务数据分析
  ↓
系统字段配置
  ↓
离线数据源 / 数据表接入
  ↓
离线指标配置
  ├─ 基本信息
  ├─ 指标模板
  ├─ 主属性 / 从属性
  ├─ 计算逻辑
  └─ 过滤条件
  ↓
离线指标测试
  ↓
指标上线
  ↓
指标审核
  ↓
离线指标调度计算
  ↓
指标授权
  ↓
决策引擎规则 / 模型 / 评分卡 / 函数 / 决策工具引用
```

关键判断：离线指标有延迟，且通常不适合用动态字段和实时场景过滤。规则效果异常时检查离线调度是否完成、结果是否入缓存、查询维度是否一致。

## 4. 决策引擎内的指标使用点

| 决策组件 | 指标使用方式 |
|---|---|
| 规则 | 条件变量，例如次数、金额、关联个数、风险评分阈值 |
| 规则集 | 查看引用变量、执行规则、输出规则集结果 |
| 决策流 | 在规则集、判断、函数、模型、评分卡等节点中间接或直接使用 |
| 决策工具 | 决策树、决策表、决策矩阵的输入变量 |
| 函数 | 函数入参或中间计算变量 |
| 评分卡 | 分箱变量、评分变量、等级映射变量 |
| 模型 | 模型特征入参 |
| 规则免疫 | 免疫条件可使用字段或指标 |
| 策略免打扰 | 免打扰条件可使用字段或指标 |
| 决策调用详情 | 展示指标查询名称、标识、类型、值 |
| 策略全景视图 | 展示策略引用的指标、字段、规则集、模型、函数等资产 |

## 5. 策略执行链路

```text
业务请求
  ↓
匹配场景策略
  ↓
选择策略版本
  ├─ 普通发布：主版本直接生效
  ├─ 分流发布：按比例 / 条件选择版本
  └─ 旁路发布：主版本生效，旁路版本仿真
  ↓
执行策略
  ├─ 简易模式：规则集组合执行
  └─ 流模式：节点编排执行
  ↓
生成风险决策
  ↓
记录日志并进入分析闭环
```

## 6. 回测中的指标注意事项

回测不是简单“拿当前指标值跑历史数据”。应按历史时点恢复指标上下文。

- 实时指标：需要历史分片、逐笔计算或铺底，否则窗口类指标可能偏低。
- 离线指标：需要历史调度结果；如果历史未计算，可能只能跳过或用已有结果近似。
- 外数指标：要明确是重新调用、使用历史缓存，还是跳过。
- 动态字段：历史请求或数据集中必须能提供或重算。
- 策略版本：必须确认回测的是编辑区版本、运行区版本，还是某个历史发布版本。
