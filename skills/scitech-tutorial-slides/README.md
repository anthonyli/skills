# Scitech Tutorial Slides

将主题、Markdown、文章或笔记转换为深色未来科技教程风格的独立 HTML 幻灯片。适合录课、知识讲解、技术科普、课程内容和 explainer deck。

## 适用场景

- 根据一个主题生成教程 slides
- 把 Markdown、文章、笔记或大纲转换成 HTML slide deck
- 制作深色玻璃拟态、科技感、动画化的课程内容
- 在用户明确要求时，内嵌中文讲稿、旁白稿、speaker notes 或录屏文案

## 资源

- `references/html-skeleton.md`
- `references/style-guide.md`
- `agents/openai.yaml`

## 输出

默认输出一个单文件 HTML slide deck，包含内联 CSS 和 JavaScript，支持键盘导航、进度条、页码、全屏、窄屏适配和打印样式。
