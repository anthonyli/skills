# Example Skill

This is a small example skill that demonstrates the expected repository format.

## When To Use

Use this skill when you are inspecting this template repository or creating a new skill from the bundled template.

## Workflow

1. Read the user's goal.
2. Locate the skill directory in `skills/`.
3. Check `SKILL.md`, `skill.json`, and `i18n/`.
4. Explain what should be copied or edited.

## Output

Give the user a concise checklist of files to update and validation commands to run.
