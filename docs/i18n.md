# Internationalization

This template supports four locales:

- `zh-CN`
- `en`
- `ja`
- `ko`

## Where Text Lives

Root repository docs:

- `README.md`: Simplified Chinese
- `README.en.md`: English
- `README.ja.md`: Japanese
- `README.ko.md`: Korean

Per-skill display text:

```text
skills/<skill-id>/i18n/
├── zh-CN.json
├── en.json
├── ja.json
└── ko.json
```

## What To Translate

Each locale file should include:

```json
{
  "name": "Localized name",
  "summary": "Short localized summary.",
  "description": "Longer localized description.",
  "keywords": ["keyword"]
}
```

Keep `summary` short enough for lists and cards. Put details in `description`.

## What Not To Translate

Do not translate:

- `id`
- directory names
- filenames
- `registry.json` field names
- `skill.json` field names

Stable IDs make the repository easier for tools to index.

## Maintenance Checklist

When adding a skill:

1. Update all four files in `i18n/`.
2. Update `summary` in `skill.json`.
3. Update `summary` in `registry.json`.
4. Run `npm run validate`.
