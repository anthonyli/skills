# Futuristic Tech Slides

生成未来科技感 HTML 演示文稿的 skill。它适合技术发布、开发者演讲、产品架构讲解、硬科技主题展示等场景。

## 适用场景

- 生成 cyberpunk / hard-tech / futuristic 风格的 HTML slides
- 为技术深潜、产品发布、开发者内容制作高视觉冲击力演示
- 使用霓虹色、glitch 标题、粒子背景、3D tilt 卡片和 reveal 动效
- 需要可直接浏览器打开、可编辑、16:9 的单文件演示文稿

## 资源

- `assets/template.html`
- `references/tech-patterns.md`

## 输出

默认生成单个 HTML 文件，包含内联 CSS / JS，并要求文字节点可编辑。
